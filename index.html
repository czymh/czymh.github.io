About

I am a Ph.D. student at the Department of Astronomy, Shanghai Jiao Tong University. My research centers on large-scale structure and cosmology, with an emphasis on cosmological N-body simulations, weak gravitational lensing, and emulator-based modeling of the universe.

  • Cosmological simulations
  • Large-scale structure
  • Weak gravitational lensing
  • Cosmological emulators
  • Power spectrum & halo mass function

Projects & Software

Tools and simulation suites I develop and maintain.

Kun Simulation

Simulation suite

Public repository for the Kun simulation suite — 129 high-resolution N-body simulations (modified Gadget-4) spanning 129 cosmologies, built for the CSST Emulator.

Documentation GitHub

CSST Emulator

Python package

A user-friendly Python package for the CSST cosmological emulator — predicts matter power spectrum, halo mass function, and more, trained on the Kun suite.

Documentation GitHub

pyFFTps

Python package

Fast and user-friendly power-spectrum calculation Python package for N-body simulations.
